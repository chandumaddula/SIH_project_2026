# Statutory Amendments History

This directory records official amendments to the Legal Metrology (Packaged Commodities) Rules, 2011:

1. **G.S.R. 779(E) (2021 Amendment)**: Mandatory inclusion of Unit Sale Price, simplified net quantity declaration rules, mandate for mandatory declarations on e-commerce platforms. Effective April 1, 2022.
2. **G.S.R. 533(E) (2022 Amendment)**: Revisions to font height specifications and alignment rules.
3. **G.S.R. 182(E) (2024 Amendment)**: E-commerce seller disclosures and digital QR code labeling provisions.
